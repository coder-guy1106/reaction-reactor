
# reaction-reactor
literally just a silly little game🤗


the reaction reactor is a simple little circuit that tests your reaction time. when a button is pressed, a light turns yellow for a random amount of time ranging from 5-10 seconds after which it will turn green. when the light is green, a stopwatch starts and can only be ended by pressing the button again, testing how fast you reacted
